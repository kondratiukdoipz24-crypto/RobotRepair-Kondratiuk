# Robot Repair

## Опис проєкту
Це 2D-гра, створена в Unity. Гравець керує роботом, який пересувається локацією, зустрічає ворогів і може запускати снаряди, щоб їх ремонтувати.

## Керування
- **WASD або стрілки** — рух робота.
- **Пробіл** — запуск снаряда.

## Реалізовані можливості
- Анімації руху робота в чотирьох напрямках.
- Анімації руху ворога.
- Рух ворога з випадковою зміною напрямку.
- Обмеження руху ворога межами камери.
- Система здоров’я робота та ворога.
- Тимчасова зупинка ворога після отримання шкоди.
- Запуск снарядів і їх знищення після зіткнення.
- Використання Rigidbody2D та Collider2D.

## Технічні деталі
Для руху персонажів використано Rigidbody2D, а для анімацій — Animator. Зіткнення обробляються за допомогою Collider2D та методів OnTriggerEnter2D.

## Висновок
Під час роботи я навчилася створювати анімації персонажів, налаштовувати фізику та колайдери, працювати зі здоров’ям об’єктів і реалізовувати взаємодію між роботом, ворогами та снарядами.
